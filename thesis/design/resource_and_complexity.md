# Resource scaling and per-size table

Symbols: image size **\(N \in \{4,8,16\}\)** (power of two), **\(N_{\text{pix}} = N^2\)**, position qubits **\(m = 2\log_2 N\)**, color qubit **1**.

## 1. Empirical reference (initialize-only)

Transpiled metrics below are **demo outputs** from:

**`outputs/frqi_qhed_sobel_metrics.csv`**

Generated by **`python scripts/demo_frqi_qhed_sobel.py`** with basis **`cx,rz,sx`**, optimization level **3**, circuit kind **`initialize`** (`frqi_circuit_kind` column).

These columns are **reference only** — they do **not** match the structural multi-controlled-Ry.

## 2. Asymptotic scaling (structural)

| Layer | Qubits (data) | Ancilla (v-chain, reused) | CX / two-qubit scaling (order) | Depth scaling (order) |
|--------|----------------|---------------------------|--------------------------------|------------------------|
| Naive \(m\)-controlled Ry (no dedicated ancilla; worst-case decomposition) | \(m+1\) | 0 | \(N_{\text{pix}} \cdot \Theta(2^m) = \Theta(N^4)\) | Same order class (per-pixel exponential in \(m\)) |
| Improved: per-pixel v-chain MCX + C-Ry + uncompute | \(m+1\) | \(\le m-2\) (for \(m\ge 3\)) | \(N_{\text{pix}} \cdot O(m) = O(N^2 \log N)\) | \(O(N^2 \log N)\) sequential |

**Notes:**

- Constants depend on basis (`cx,rz,sx`), layout, and whether **\(Ry\)** is synthesized from **\(rz,sx\)**.
- Parallelizing pixel blocks is **not** assumed in the table; a parallel schedule would change depth but not total CX order unless shared ancillas forbid overlap.
